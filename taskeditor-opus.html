task-id: rev-backend-api · created 2026-02-23 · last run 12m ago

Objective

Build review schema, migrations, and REST endpoints for the core review system. The API must support CRUD operations for reviews, with pagination, filtering by product/user, and rating aggregation.

Implementation Steps

  1. Create reviews table migration with Drizzle ORM — columns: id, product_id, user_id, rating (1-5), title, body, created_at, updated_at
  2. Add composite index on (product_id, created_at) for listing queries
  3. Implement GET /api/reviews — paginated list, filterable by product_id and rating range
  4. Implement POST /api/reviews — validated input, authenticated user_id from JWT
  5. Implement PATCH /api/reviews/:id — author-only update with ownership check
  6. Implement DELETE /api/reviews/:id — soft delete (set deleted_at)
  7. Add GET /api/reviews/stats/:product_id — average rating, count, distribution histogram

Architecture Notes

Schema follows the patterns established in review-system-architecture.md. Use the shared withPagination() helper from src/lib/db/pagination.ts. All endpoints go through the existing auth middleware — no new auth logic needed.

Scope Boundaries

  • Do NOT modify the auth middleware or user schema
  • Do NOT add UI components — this is backend only
  • Do NOT implement email notifications for new reviews (separate task)

Testing

  • Integration test for review CRUD endpoints
  • Unit test for rating aggregation query
  • Schema migration runs cleanly on empty DB
  • Verify JWT auth rejection for unauthenticated requests
