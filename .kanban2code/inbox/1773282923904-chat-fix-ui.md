# Chat fix ui

## Audit
- src/webview/ui/index.tsx
- src/webview/ui/styles.css

## Refined Prompt

Objective: Update the sidebar UI to be more compact by hiding context/skills/LLM selector sections by default, remove placeholder messages, and add Alibaba as a provider option.

Implementation approach:
1. Add collapsible toggle buttons to Context, Skills, and Provider sections in the footer
2. Remove hardcoded placeholder messages from the chat history section
3. Add Alibaba provider option to the provider dropdown alongside existing providers

Key decisions:
- Collapsed state should persist using VS Code state API: Store visibility state in `vscodeApi.setState/getState`
- Hidden sections should show a small indicator/count when collapsed
- Alibaba should appear as "alibaba" in the provider dropdown

Edge cases:
- Provider dropdown should gracefully handle if no providers are configured
- Collapsed state should not break existing chip/add dropdown functionality

Questions:
- Where is the Alibaba API key stored? Is it in VS Code settings, a config file, or environment variable?
