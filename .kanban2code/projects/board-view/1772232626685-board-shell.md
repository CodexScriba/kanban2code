Implement the Kanban board UI shell as a static, styled webview panel in the editor area, using `kanbanboard-codex.html` as a design template. The board should open when the "Kanban" button is clicked in the sidebar.

## Refined Prompt

Objective: Implement the Kanban board UI shell as a managed webview panel, using the provided mockup as a design reference.

Implementation approach:
1. **Build Pipeline:** Update `esbuild.mjs` to use an object for `entryPoints`. Map `src/webview/ui/index.tsx` to `webview` and `src/webview/ui/board.tsx` to `board`. This ensures we get separate `board.js` and `board.css` outputs.
2. **Panel Management:** Create `src/webview/KanbanPanel.ts`. Implement a singleton class that wraps `vscode.WebviewPanel`. It should handle HTML generation with a proper CSP, nonces, and asset resolution for the `board` bundle.
3. **UI Implementation:** Create `src/webview/ui/board.tsx` and `board.css`. Port the HTML structure and CSS from `kanbanboard-codex.html` verbatim. Use vanilla DOM manipulation to mount the UI into `#app`.
4. **Wiring:** 
    - In `SidebarProvider.ts`, add a click listener to `#viewKanbanBtn` that posts a `show-kanban` message.
    - In `extension.ts`, listen for this message and call `KanbanPanel.createOrShow(context.extensionUri)`.
    - Register `kanban2code.openBoard` as a command that also triggers the panel.

Key decisions:
- **Named Bundles:** Using named entry points in esbuild allows the sidebar and board to remain decoupled and optimized.
- **Vanilla DOM:** Maintain consistency with the existing sidebar implementation by avoiding a React runtime for now.
